# Avatar 3D en Blender

Grok no controla Blender en tu PC. Tú corres el script.

Blender 4.x → Scripting → Open
`~/Escritorio/jarvis-linux/tools/blender_jarvis_avatar.py`
Run Script.

Exporta:
- `~/.local/share/jarvis-linux/avatar.glb`
- `~/Escritorio/jarvis-linux/assets/jarvis_humanoid.glb`

En Jarvis: clic derecho → Avatar humanoide.
